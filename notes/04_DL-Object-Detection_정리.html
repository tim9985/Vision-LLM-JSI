A

Bounding Box

객체 탐지 = 위치 추정 + 이미지 분류

객체 탐지(Object Detection)는 Localization(어디에)과 Image Classification(무엇이)을 결합한 기술이다. 하나의 이미지에서 여러 객체를 동시에 인식하며, 각 객체는 Bounding Box(위치) + Class(종류) + Confidence(신뢰도) 세 값으로 표현된다.

규칙기반 (Rule-based)

  • 사람이 색·크기·형태 규칙을 직접 설정
  • + 학습 데이터 불필요
  • − 환경이 바뀌면 규칙을 다시 수정
  • − 조명 · 배경 · 크기 변화에 민감

학습기반 (Learning-based)

  • 모델이 데이터에서 특징을 학습
  • + 복잡한 배경 · 다양한 변화에 대응
  • − 많은 데이터와 연산 필요
  • − 내부 판단 과정 해석이 어려움

BBox 표현 방식 4가지

같은 박스를 네 가지로 쓸 수 있다. 함수마다 요구하는 형식이 달라서 변환이 늘 필요하다.

형식구성쓰이는 곳

  • cxcywh → xyxy   x1 = cx − w/2, y1 = cy − h/2
  • 정규화   cx_norm = cx / image_width (w, h도 동일)

B

Intersection over Union

두 박스가 얼마나 겹치는가

IoU는 교집합 면적 ÷ 합집합 면적이다. 교집합은 언제나 합집합의 부분이므로 값은 항상 0 ≤ IoU ≤ 1이며, 0이면 전혀 안 겹침 · 1이면 완전히 동일하다.

교집합 면적합집합 면적 = IoU   ·   합집합 = A + B − 교집합

A와 B를 그냥 더하면 겹친 부분이 두 번 세어지므로 교집합을 정확히 한 번 빼야 한다.

교집합 좌표가 찍히는 위치

왜 두 개는 max이고 두 개는 min인가
  • 좌상단 둘 다 겹치려면 더 늦게 시작한 쪽부터 → 좌표값이 큰 쪽 → max
  • 우하단 둘 다 겹치려면 더 먼저 끝난 쪽까지 → 좌표값이 작은 쪽 → min
  • 결국 항상 더 안쪽 벽을 고르는 것 — 교집합은 안쪽 벽 넷으로 둘러싸인 방이다
  • 교집합의 꼭짓점은 새로 계산된 점이 아니라 두 박스의 꼭짓점 중 하나가 선택된 것이다
calculate_iou.py노트북 셀 30 — 완성 코드
def calculate_iou(bbox_a, bbox_b):
    xa_1, ya_1, xa_2, ya_2 = bbox_a
    xb_1, yb_1, xb_2, yb_2 = bbox_b

    # 교집합 영역의 좌표
    intersection_x1 = max(xa_1, xb_1)
    intersection_y1 = max(ya_1, yb_1)
    intersection_x2 = min(xa_2, xb_2)
    intersection_y2 = min(ya_2, yb_2)

    # 겹치지 않으면 음수가 되므로 0으로 clamp
    intersection_width  = max(0, intersection_x2 - intersection_x1)
    intersection_height = max(0, intersection_y2 - intersection_y1)
    intersection_area   = intersection_width * intersection_height

    area_a = (xa_2 - xa_1) * (ya_2 - ya_1)
    area_b = (xb_2 - xb_1) * (yb_2 - yb_1)
    union_area = area_a + area_b - intersection_area

    if union_area == 0:      # ZeroDivisionError 방지
        return 0.0

    return intersection_area / union_area
함정

max(0, ...)는 폭과 높이 각각에 걸어야 한다. 두 박스가 대각선으로 떨어지면 폭·높이가 둘 다 음수가 되어 곱이 양수가 되고, 겹치지 않는데도 그럴듯한 IoU가 나온다. max(0, w*h)로 곱한 뒤 거는 건 무의미하다.

C

Non-Maximum Suppression

한 객체에 하나의 박스만 남기기

객체 하나에 대해 모델이 여러 개의 박스를 높은 신뢰도로 예측하는 일이 흔하다. NMS는 Confidence가 가장 높은 박스를 기준으로, 그와 많이 겹치는 박스를 제거하는 과정을 반복해 객체마다 대표 박스 하나만 남긴다.

NMS 알고리즘 — 두 개의 임계값이 쓰인다
  • 0. Confidence Thresholding — 신뢰도가 너무 낮은 박스를 먼저 통째로 제거
  • 1. 남은 것 중 Confidence가 가장 높은 박스를 선택해 결과에 넣는다
  • 2. 선택한 박스와 나머지 박스들의 IoU를 계산
  • 3. IoU가 임계값보다 높은 박스를 제거 (같은 객체로 간주)
  • 4. 남은 박스가 없을 때까지 1~3 반복

conf_threshold

  • 박스를 얼마나 믿을지의 기준
  • 높이면 검출 수 감소, 오탐 감소

iou_threshold

  • 박스를 같은 객체로 볼지의 기준
  • 낮출수록 더 공격적으로 제거
nms.py직접 구현 — 노트북 셀 51 · 52 정답
def prune_low_conf(boxes, scores, conf_threshold=0.5):
    pruned_boxes, pruned_scores = [], []

    for box, score in zip(boxes, scores):
        if score >= conf_threshold:
            pruned_boxes.append(box)
            pruned_scores.append(score)

    return pruned_boxes, pruned_scores


def apply_nms(boxes, scores, iou_threshold=0.5):
    if len(boxes) == 0:
        return [], []

    # Confidence 내림차순 인덱스 (argsort는 오름차순이라 뒤집는다)
    order = np.argsort(scores)[::-1].tolist()

    nms_boxes, nms_scores = [], []

    while order:
        current = order.pop(0)          # 가장 높은 Confidence
        nms_boxes.append(boxes[current])
        nms_scores.append(scores[current])

        # 많이 겹치는 박스는 같은 객체 → 제거
        order = [
            i for i in order
            if calculate_iou(boxes[current], boxes[i]) <= iou_threshold
        ]

    return nms_boxes, nms_scores
nms_cv2.py⚠ cv2.dnn.NMSBoxes는 (x, y, w, h)를 받는다
# xyxy → xywh 변환이 반드시 필요하다
boxes_xywh = [[int(x1), int(y1), int(x2-x1), int(y2-y1)] for x1,y1,x2,y2 in boxes]

keep_indices = cv2.dnn.NMSBoxes(
    bboxes=boxes_xywh,
    scores=scores,
    score_threshold=conf_threshold,   # Confidence Thresholding까지 함께 처리
    nms_threshold=iou_threshold,
)

keep_indices = np.array(keep_indices).reshape(-1).tolist()   # 1차원으로 평탄화

nms_boxes  = [boxes[i]  for i in keep_indices]     # 원래 xyxy에서 선택
nms_scores = [scores[i] for i in keep_indices]
POINT

NMS 후에도 남아 있는 중복 박스는 버그가 아니다 — 겹친 면적이 작거나 합집합이 넓어 IoU가 임계값 아래인 경우다. cv2.dnn.NMSBoxes는 직접 구현과 동일한 결과를 주지만, 내부적으로 xywh 형식을 쓰고 인덱스를 반환한다는 두 가지 차이를 기억할 것.

D

YOLO 개요 · 설치

One-stage Detector · COCO 사전학습

YOLO(You Only Look Once)는 이미지 전체를 신경망에 한 번 넣어 위치·종류·신뢰도를 동시에 예측하는 CNN 기반 One-stage Detector다. 별도의 Region Proposal 단계가 없고 Feature Map을 여러 객체가 공유하며 여러 위치의 예측을 병렬로 계산하기 때문에 GPU 병렬 연산과 궁합이 좋아 실시간 처리에 적합하다.

모델 이름 읽는 법 — YOLO11n
  • YOLO 모델 이름 (You Only Look Once)
  • 11 버전 (V1부터 발전, 최신은 YOLO26까지 출시)
  • n 모델 크기 및 파라미터 수 (n · s · m · l · x)
크기약자특징
nNano경량화 모델 — 속도 최우선, 연산량 적음
sSmall가벼우면서 적절한 성능
mMedium속도와 정확도의 균형
lLarge높은 정확도
xExtra Large최고 성능, 높은 연산량 필요

본 수업이 최신 YOLO26이 아니라 YOLO11n을 쓰는 이유는 셋이다 — ① PyTorch·OpenCV와의 의존성 충돌 위험이 낮고, ② Nano는 연산량이 적어 Jetson에서 실시간이 가능하며, ③ 가중치 파일이 가벼워 실습 회전이 빠르다.

COCO 데이터셋 — YOLO 기본 모델이 이미 학습한 것
  • Microsoft가 만든 대규모 객체 탐지 · 분할 데이터셋
  • 80가지 클래스 — 사람, 자동차, 강아지, 의자 등 일상 객체
  • 여러 객체가 어우러진 실제 환경 이미지가 다수 → 실전 인식 성능이 높음
  • 그래서 추가 학습 없이 바로 사람·차량·동물을 탐지할 수 있다

E

YOLO 실시간 객체 탐지

GStreamer 프레임 루프에 모델을 얹는다

Computer Vision 섹션의 GStreamer 파이프라인 + while 루프를 그대로 쓰고, 프레임마다 model.predict()를 호출하면 끝이다. 새로운 개념은 없다.

yolo_realtime.pyJupyter가 아닌 .py 파일로 실행
model = YOLO("src/models/YOLO/yolo11n.pt")
model.to("cuda")

pipeline = (
    "nvarguscamerasrc sensor-id=0 ! "
    "video/x-raw(memory:NVMM), width=1280, height=720, framerate=30/1 ! "
    "nvvidconv ! video/x-raw, format=BGRx ! "
    "videoconvert ! video/x-raw, format=BGR ! "
    "queue leaky=downstream max-size-buffers=1 ! "
    "appsink drop=true max-buffers=1 sync=false"
)
cap = cv2.VideoCapture(pipeline, cv2.CAP_GSTREAMER)

while True:
    ret, frame = cap.read()
    if not ret or cv2.waitKey(1) & 0xFF == ord("q"):
        break

    results = model.predict(source=frame, conf=0.25, iou=0.5,
                            verbose=False, classes=None)   # verbose=False 필수!

    cv2.imshow("YOLO Object Detection", results[0].plot())

cap.release(); cv2.destroyAllWindows()
파이프라인에서 지연을 줄이는 두 옵션
  • queue leaky=downstream max-size-buffers=1 — 밀린 프레임을 버려 큐가 쌓이지 않게 한다
  • appsink drop=true max-buffers=1 sync=false — 항상 가장 최신 프레임만 읽는다
  • 이 둘이 없으면 추론이 느릴 때 화면이 점점 과거를 보여주게 된다
실습 팁

Jupyter에서는 OpenCV GUI(cv2.imshow)가 동작하지 않으므로 별도 .py 파일로 실행한다. 루프 안에서 verbose=False를 빼면 매 프레임 로그가 쏟아져 그 자체로 FPS가 떨어진다.

F

성능 평가 — FPS

체감 성능은 추론 속도가 아니다
FPS = 1 / 프레임_처리_시간(s) = 1000 / 프레임_처리_시간(ms)

추론 FPS

  • 모델 Forward 속도만 측정
  • 벤치마크 숫자로는 예쁘지만
  • 실제 체감과 다름

End-to-End FPS

  • 프레임 입력 + 전처리 + 추론
  • + NMS + BBox 시각화 + 화면 출력
  • 이것이 실제 성능

매 프레임 FPS를 그대로 표시하면 순간적인 Bottleneck·프레임 드롭 때문에 숫자가 심하게 요동친다. 지수 이동 평균(EMA)으로 이전 값과 현재 값을 가중 결합하면, 최신 변화를 반영하면서도 급격한 노이즈를 완화할 수 있다.

displayed_fps = 0.9 × 이전_fps + 0.1 × 현재_fps
fps_ema.py루프 전체를 감싸야 End-to-End가 된다
displayed_fps = 0.0

while True:
    start_time = time.perf_counter()      # ← 프레임 읽기 '전'부터 측정

    ret, frame = cap.read()
    results = model.predict(source=frame, conf=0.25, iou=0.5, verbose=False)
    output_frame = results[0].plot()

    elapsed_time = time.perf_counter() - start_time
    current_fps = 1.0 / elapsed_time

    if displayed_fps == 0:
        displayed_fps = current_fps                              # 첫 프레임은 그대로
    else:
        displayed_fps = 0.9 * displayed_fps + 0.1 * current_fps   # EMA

    cv2.putText(output_frame, f"FPS: {displayed_fps:.1f}", (20,40),
                cv2.FONT_HERSHEY_SIMPLEX, 1.0, (0,255,0), 2)

B. 좌표 변환 · IoU (셀 30)

iou.pyZeroDivisionError 처리까지
def convert_bbox_coord(bbox):
    x, y, w, h = bbox
    return (x, y, x + w, y + h)


def calculate_iou(bbox_a, bbox_b):
    xa_1, ya_1, xa_2, ya_2 = bbox_a
    xb_1, yb_1, xb_2, yb_2 = bbox_b

    intersection_x1 = max(xa_1, xb_1)
    intersection_y1 = max(ya_1, yb_1)
    intersection_x2 = min(xa_2, xb_2)
    intersection_y2 = min(ya_2, yb_2)

    intersection_width  = max(0, intersection_x2 - intersection_x1)
    intersection_height = max(0, intersection_y2 - intersection_y1)
    intersection_area   = intersection_width * intersection_height

    area_a = (xa_2 - xa_1) * (ya_2 - ya_1)
    area_b = (xb_2 - xb_1) * (yb_2 - yb_1)
    union_area = area_a + area_b - intersection_area

    if union_area == 0:
        return 0.0

    return intersection_area / union_area

def prune_low_conf(boxes, scores, conf_threshold=0.5):
    pruned_boxes = []
    pruned_scores = []

    for box, score in zip(boxes, scores):
        if score >= conf_threshold:
            pruned_boxes.append(box)
            pruned_scores.append(score)

    return pruned_boxes, pruned_scores
apply_nms.py공식 정답 — NumPy Boolean 인덱싱으로 한 번에 거른다
def apply_nms(boxes, scores, iou_threshold=0.5):
    boxes  = np.array(boxes,  dtype=np.float32)
    scores = np.array(scores, dtype=np.float32)

    # Confidence Score가 높은 순서대로 index 정렬 (argsort는 오름차순이라 뒤집는다)
    sorted_indices = np.argsort(scores)[::-1]

    keep_indices = []

    while len(sorted_indices) > 0:
        # 현재 가장 높은 Confidence Score를 가진 박스 선택
        current_index = sorted_indices[0]
        keep_indices.append(current_index)

        if len(sorted_indices) == 1:
            break

        remaining_indices = sorted_indices[1:]
        remaining_boxes   = boxes[remaining_indices]

        # 선택된 박스와 나머지 박스들의 IoU 계산
        iou_values = []
        for remaining_box in remaining_boxes:
            iou_values.append(calculate_iou(boxes[current_index], remaining_box))
        iou_values = np.array(iou_values)

        # IoU가 Threshold 이하인 박스만 유지 ← Boolean 인덱싱
        sorted_indices = remaining_indices[iou_values <= iou_threshold]

    nms_boxes  = boxes[keep_indices].astype(int).tolist()
    nms_scores = scores[keep_indices].tolist()

    return nms_boxes, nms_scores
코드 읽는 법

핵심은 마지막에서 두 번째 줄입니다. remaining_indices[iou_values <= iou_threshold] — Boolean 배열로 인덱싱해 조건을 만족하는 인덱스만 한 번에 남깁니다(01 세션의 Boolean 마스크가 여기 쓰입니다). 반복문으로 하나씩 지우는 것보다 짧고 빠릅니다.

이 구현은 cv2.dnn.NMSBoxes와 동일한 결과를 냅니다(시드 4개로 확인). 다만 정답 버전은 boxes를 np.array로 바꾸므로 반환값이 리스트의 리스트가 되고, 좌표가 int로 잘립니다.
