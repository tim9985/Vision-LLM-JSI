A

이미지 조정

이미지는 결국 NumPy 배열이다

이미지는 H × W × C 형태의 NumPy 배열이다. image.shape로 세로(행) · 가로(열) · 채널 수를 확인하고, image[row, col]로 픽셀 하나를 인덱싱할 수 있다. 원점(origin)은 좌측 상단이며 row가 증가하면 아래로, column이 증가하면 오른쪽으로 이동한다.

픽셀 값은 기본적으로 uint8 타입에 [0, 255] 범위로 저장된다. 실수 연산(색공간 변환, 필터링 등)을 하려면 float32로 바꾸고 255로 나눠 [0, 1] 범위로 정규화해야 Matplotlib이 올바르게 렌더링한다.

image_basics.pyNumPy indexing / slicing / dtype 변환
import cv2
import numpy as np

image = skimage.data.astronaut()
image.shape                      # (512, 512, 3) → H x W x C
image[0, 0]                     # 픽셀 하나 = [R, G, B], dtype uint8

# NumPy slicing = crop
cropped = image[0:100, 0:50]

# OpenCV 회전 / 반전
cv2.rotate(image, cv2.ROTATE_90_CLOCKWISE)
cv2.flip(image, 1)          # 1: 좌우, 0: 상하, -1: 상하좌우

# uint8 [0,255] → float32 [0,1] 정규화
image_f = image.astype(np.float32) / 255.
POINT

cv2.flip의 flipCode: 1=좌우반전, 0=상하반전, -1=상하좌우 모두. 색공간/필터 연산 전에는 항상 float32 정규화 여부를 먼저 확인한다.

B

색공간 변환

RGB · BGR · Grayscale · HSV

Matplotlib은 RGB, OpenCV는 BGR 순서를 기본으로 사용한다. cv2.imread()로 읽은 이미지를 Matplotlib으로 그대로 띄우면 파랑/빨강이 뒤바뀌어 보이는 이유다. 반드시 cv2.cvtColor(img, cv2.COLOR_BGR2RGB)로 변환해야 한다.

주의 — RGB2GRAY vs BGR2GRAY
  • skimage.data.astronaut()는 RGB 순서 → COLOR_RGB2GRAY 사용
  • cv2.imread()는 BGR 순서 → COLOR_BGR2GRAY 사용
  • 순서를 착각해도 에러는 안 나지만, R/B 채널 가중치가 바뀌어 미묘하게 다른 흑백 이미지가 나온다
Gray = 0.299 × R + 0.587 × G + 0.114 × B

사람 눈은 초록에 가장 민감하고 파랑에 가장 둔감하기 때문에 단순 평균이 아닌 가중합을 사용한다.

HSV 색공간

H (Hue, 색상) — 원 둘레 각도. 0~360°(일반) / OpenCV uint8은 0~179
S (Saturation, 채도) — 중심에서 바깥으로. 0(회색)~1(원색)
V (Value, 명도) — 밝기. 0(검정)~1(원색 밝기)
색상·채도·명도가 서로 독립적이라, 채널을 나눠 조절하면 색만/채도만/밝기만 바꿀 수 있다.
채널일반 범위OpenCV uint8OpenCV float32
H (색상)0° ~ 360°0 ~ 1790.0 ~ 360.0
S (채도)0 ~ 100%0 ~ 2550.0 ~ 1.0
V (명도)0 ~ 100%0 ~ 2550.0 ~ 1.0
hsv_channel_edit.pyH 회전 / S 감쇠 / V 증폭
image_hsv = cv2.cvtColor(image, cv2.COLOR_RGB2HSV)
h, s, v = cv2.split(image_hsv)

h = (h + 45) % 360              # 색상 45도 회전 (360 넘으면 순환)
s = np.clip(s * 0.3, 0, 1)        # 채도 30%로 감쇠 + 범위 clip
v = np.clip(v * 2.5, 0, 1)        # 명도 2.5배 증폭 + 범위 clip

image_hsv = cv2.merge((h, s, v))
image_rgb = cv2.cvtColor(image_hsv, cv2.COLOR_HSV2RGB)
POINT

float32 HSV에서 채널을 조작한 뒤에는 반드시 np.clip으로 유효 범위(S,V: 0~1 / H: %360)를 지켜야 색이 깨지지 않는다.

Box Filter — cv2.blur()

  • 커널 내 픽셀 단순 평균
  • 빠르지만 경계가 뭉개짐

Gaussian Filter — cv2.GaussianBlur()

  • 중심에 가까울수록 가중치 ↑
  • Box보다 자연스러운 블러
filtering.pyBlur · Sharpen · Border Type
# Smoothing
box_blur      = cv2.blur(image, (11,11))
gaussian_blur = cv2.GaussianBlur(image, (11,11), 0)

# Sharpening — OpenCV엔 내장 함수가 없어 커널을 직접 정의
sharp_kernel = np.array([[0,-1,0],
                          [-1,5,-1],
                          [0,-1,0]], dtype=np.float32)
sharpened = cv2.filter2D(image, cv2.CV_32F, sharp_kernel)
sharpened = np.clip(sharpened, 0, 1)

# Border Type — 커널이 테두리를 벗어날 때 처리 방식
cv2.blur(image, (101,101), borderType=cv2.BORDER_REFLECT_101)
POINT

cv2.filter2D(src, ddepth, kernel)에서 ddepth=-1은 원본과 같은 데이터 타입 유지. Kernel 크기가 클수록 블러 강도는 세지지만 연산 비용도 커진다.

D

Edge Detection

고주파 성분 = 경계선

저주파(하늘·피부처럼 부드러운 영역)는 LPF(Box/Gaussian)로 남기고, 고주파(경계·질감·노이즈)는 HPF로 뽑아낸다. Edge Detection은 대표적인 HPF 응용이다.

residual_unsharp.pyResidual Extraction → Unsharp Masking
gray  = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY).astype(np.float32) / 255.
blur  = cv2.GaussianBlur(gray, (55,55), 0)     # 저주파 성분
high  = cv2.subtract(gray, blur)          # 원본 - 저주파 = 고주파(윤곽선 스케치)
sharp = cv2.add(gray, high)               # 원본 + 고주파 = edge 강조(Unsharp Masking)

Sobel Filter — 미분 기반 Edge 검출

magnitude = √( dx2 + dy2 )
sobel.pydx, dy → magnitude
sobel_x = cv2.Sobel(gray_blur, cv2.CV_64F, 1, 0, ksize=3)  # 세로 edge (x방향 미분)
sobel_y = cv2.Sobel(gray_blur, cv2.CV_64F, 0, 1, ksize=3)  # 가로 edge (y방향 미분)

sobel_mag     = cv2.magnitude(sobel_x, sobel_y)   # √(dx² + dy²)
sobel_mag_abs = cv2.convertScaleAbs(sobel_mag)    # 절대값 → 0~255 uint8로 변환

Canny Edge Detection

4단계 파이프라인
  • 1. Gaussian Smoothing — 노이즈 제거
  • 2. Sobel Filter — edge 후보 검출
  • 3. Non-maximum Suppression — gradient 방향 기준 local maximum만 유지
  • 4. Hysteresis Thresholding — 이중 임계값 + 연결성 추적
canny.py⚠ CV_8U 입력 필수
gray = cv2.cvtColor(image, cv2.COLOR_RGB2GRAY)   # float32 변환 X — cv2.Canny는 CV_8U만 허용
edges = cv2.Canny(gray, 50, 150)             # 하위/상위 임계값

Sobel Filter

  • + 매우 빠른 속도
  • − 배경 노이즈에 취약
  • − edge가 두꺼움

Canny Edge Detection

  • + edge가 훨씬 얇고 정확
  • + NMS + Hysteresis로 노이즈 억제
  • − 연산량이 더 많음
함정

cv2.Canny에 float32 이미지를 넣으면 _src.depth() == CV_8U 에러 발생 — Sobel과 달리 정규화하면 안 된다.

E

Color Segmentation

색상 임계값 → Binary Mask

HSV로 변환한 뒤 cv2.inRange(hsv, lower, upper)로 특정 색상 범위만 흰색(255), 나머지는 검정(0)인 이진 마스크를 만든다.

빨간색은 왜 두 구간이 필요한가
  • HSV의 H는 원형(0°~360°) — 빨강은 각도 0° 근처에 위치
  • OpenCV uint8 기준 H: 0~10과 H: 170~180 두 범위를 cv2.bitwise_or로 합쳐야 빨간색 전체를 포착
color_segmentation.py빨간색 이진 마스크
hsv = cv2.cvtColor(image, cv2.COLOR_RGB2HSV)

red_lower1, red_upper1 = np.array([0,100,50]),   np.array([10,255,255])
red_lower2, red_upper2 = np.array([170,100,50]), np.array([180,255,255])

mask1 = cv2.inRange(hsv, red_lower1, red_upper1)
mask2 = cv2.inRange(hsv, red_lower2, red_upper2)
mask  = cv2.bitwise_or(mask1, mask2)

# 마스크 노이즈 제거 — 강하게 하면 정보 유실이 크므로 약하게만 적용
mask_clean = cv2.inRange(cv2.cvtColor(cv2.GaussianBlur(image,(7,7),0), cv2.COLOR_RGB2HSV), red_lower1, red_upper1)
F

Morphological Operation

이진 마스크 노이즈 정리

Erosion (침식) — AND

  • 커널 내 모든 픽셀이 흰색일 때만 흰색 유지
  • 흰 영역 축소 → 배경 노이즈 제거

Dilation (팽창) — OR

  • 커널 내 하나라도 흰색이면 흰색
  • 흰 영역 확장 → 구멍/끊어진 윤곽 연결

Opening = Erosion → Dilation

  • 작은 노이즈 점 제거
  • 전체 크기는 거의 유지

Closing = Dilation → Erosion

  • 객체 내부의 작은 구멍 메우기
  • 끊어진 영역 연결
morphology.py실전 패턴: Opening → Closing 반복 적용
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5,5))

eroded  = cv2.erode(mask, kernel, iterations=2)
dilated = cv2.dilate(mask, kernel, iterations=2)

opened = cv2.morphologyEx(mask, cv2.MORPH_OPEN,  kernel, iterations=2)  # 노이즈 제거
closed = cv2.morphologyEx(opened, cv2.MORPH_CLOSE, kernel, iterations=3)  # 끊긴 영역 연결
실습 팁

정답은 없다 — Opening/Closing의 iterations를 1~3회씩 바꿔가며 결과를 비교하고, 노이즈는 지워지되 원하는 영역의 연속성은 유지되는 조합을 찾는 게 핵심이다.

Contour Detection

외곽선 검출 → 중심점/반지름 산출

Binary Mask에서 연결된 영역의 외곽선을 찾는다. 노이즈가 작은 외곽선을 여러 개 만들기 쉬우므로, 검출 전에 Morphological Operation으로 마스크를 정리하고 검출 후에는 면적이 가장 큰 외곽선 하나만 선택하는 패턴을 사용한다.

contour_detection.pyfindContours → 최대 면적 선택 → 채우기
contours, _ = cv2.findContours(
    mask,                     # 최종 정리된 binary mask
    cv2.RETR_EXTERNAL,        # 바깥쪽 테두리만 검출
    cv2.CHAIN_APPROX_SIMPLE   # 직선 구간은 꼭짓점만 저장(메모리 절약)
)

largest = max(contours, key=cv2.contourArea)   # 면적 최대 = 노이즈 제외

final_mask = np.zeros_like(mask)
cv2.drawContours(final_mask, [largest], -1, 255, thickness=cv2.FILLED)
cv2.drawContours(frame, [largest], -1, (0,255,0), 2)   # 외곽선 그리기

최소 외접원 — minEnclosingCircle

  • 외곽선의 모든 점을 포함하는 가장 작은 원

무게중심 — moments

  • 픽셀 분포 기반 기하학적 중심
  • 반지름 정보는 없음 → 외접원과 함께 사용

I

Interest Point Extraction

Harris Corner Detection

이미지 내에서 정보량이 높은 지점(코너)을 찾는다. 크기·회전·조명 변화에도 비교적 안정적이라 이미지 비교·객체 추적의 기반이 된다. (대표: Harris Corner, SIFT, ORB)

Harris(M) ≈ G(Ix2)·G(Iy2) − G(IxIy)2 − α·[G(Ix2) + G(Iy2)]2
harris_corner.pySobel → Gaussian → Response → NMS
def harris(im, k=3, alpha=0.05):
    dx = cv2.Sobel(im, -1, dx=1, dy=0)
    dy = cv2.Sobel(im, -1, dx=0, dy=1)

    dxx = cv2.GaussianBlur(dx**2,  (k,k), sigmaX=-1)
    dyy = cv2.GaussianBlur(dy**2,  (k,k), sigmaX=-1)
    dxy = cv2.GaussianBlur(dx*dy, (k,k), sigmaX=-1)

    return dxx*dyy - dxy**2 - alpha * (dxx+dyy)**2

response = harris(np.float32(gray_img), k=11, alpha=0.05)

# Local maxima만 남겨 최종 코너 좌표 확정 (Non-Maximum Suppression)
points = np.argwhere(response > threshold)
과정 요약

Sobel(dx,dy) → Gaussian으로 dxx/dyy/dxy 평탄화 → Response 계산 → Thresholding → 8-이웃 비교로 지역 최댓값(코너)만 남김.

K

실시간 객체 검출

E · F · H 조합을 프레임 루프에 적용

정지 이미지에서 익힌 Color Segmentation → Morphological Operation → Contour Detection 파이프라인을 while 루프 안에서 매 프레임 반복하면 실시간 객체 검출이 된다. 새로운 개념은 없고, 지금까지의 기법을 프레임 단위로 재사용하는 것이 핵심이다.

realtime_detection.py프레임 루프 패턴
lower, upper = np.array([30,60,90]), np.array([230,115,180])  # LAB 기준 예시

while True:
    ret, frame = cap.read()
    lab = cv2.cvtColor(frame, cv2.COLOR_BGR2LAB)
    mask = cv2.inRange(lab, lower, upper)                                  # E. Color Segmentation
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel, iterations=2)   # F. Morphological Operation

    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)  # H. Contour
    if contours:
        c = max(contours, key=cv2.contourArea)
        (x,y), r = cv2.minEnclosingCircle(c)
        cv2.circle(frame, (int(x),int(y)), int(r), (0,255,0), 2)

    cv2.imshow("Detection", frame)

Kalman Filter — 예측(Prediction) + 보정(Update)

객체가 조명 오염·가려짐 등으로 일시적으로 검출되지 않아도, Kalman Filter는 이전 상태를 바탕으로 위치를 예측하고 새 측정값이 들어오면 보정하여 끊김 없는 추적을 가능하게 한다.

검출됨 → Predict + Update (측정값 반영)
↻
가려짐 → Predict만 (측정값 없이 추정)
kalman_filter.pycv2.KalmanFilter — 상태 [x, y, vx, vy]
kalman = cv2.KalmanFilter(4, 2)   # 상태 4차원(x,y,vx,vy), 측정 2차원(x,y)

kalman.transitionMatrix = np.array(
    [[1,0,1,0],[0,1,0,1],[0,0,1,0],[0,0,0,1]], dtype=np.float32)
kalman.measurementMatrix = np.array(
    [[1,0,0,0],[0,1,0,0]], dtype=np.float32)
kalman.processNoiseCov     = np.eye(4, dtype=np.float32) * 1e-2   # 클수록 측정값을 더 신뢰
kalman.measurementNoiseCov = np.eye(2, dtype=np.float32) * 1.0

# 최초 검출 시 초기 상태 설정
kalman.statePre = np.array([[cx],[cy],[0.],[0.]], dtype=np.float32)

if object_detected:
    kalman.predict()
    corrected = kalman.correct(np.array([[cx],[cy]], dtype=np.float32))  # 측정값으로 보정
    x_bel, y_bel = corrected[0,0], corrected[1,0]
else:  # 가려짐: 측정값 없이 예측만
    predicted = kalman.predict()
    x_bel, y_bel = predicted[0,0], predicted[1,0]

def calculate_angle(p1, p2, p3):   # p2를 중심으로 한 벡터 사이 각도
    v1 = np.array([p1.x-p2.x, p1.y-p2.y, p1.z-p2.z])
    v2 = np.array([p3.x-p2.x, p3.y-p2.y, p3.z-p2.z])
    cosine = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
    return np.degrees(np.arccos(np.clip(cosine, -1.0, 1.0)))

angle_threshold = 160   # 이 각도 이상이면 '펴짐'으로 판정
finger_joints = [(1,2,3), (5,6,7), (9,10,11), (13,14,15), (17,18,19)]

extended = sum(
    calculate_angle(hand[a], hand[b], hand[c]) > angle_threshold
    for a,b,c in finger_joints
)
